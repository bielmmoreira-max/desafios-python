# 🐍 Desafios de Python — Mundos 1, 2 e 3

Este repositório contém a minha evolução prática e as resoluções dos exercícios de Python do curso **Curso em Vídeo**, ministrado pelo professor **Gustavo Guanabara**.

---

## 📌 Conteúdos Praticados por Mundo

### 🔹 Mundo 1 — Fundamentos
- Primeiros passos e configuração do ambiente
- Tipos primitivos e saída de dados
- Operadores aritméticos
- Módulos e bibliotecas padrão
- Manipulação de texto (Strings)
- Estruturas condicionais (`if` / `else`)

### 🔹 Mundo 2 — Estruturas de Controle
- Condicionais aninhadas (`if` / `elif` / `else`)
- Estrutura de repetição `for`
- Estrutura de repetição `while` (e interrupção com `break`)

### 🔹 Mundo 3 — Estruturas Compostas e Avançadas
- Tuplas, Listas e Dicionários
- Funções e escopo de variáveis
- Modularização e Pacotes (criação de módulos e bibliotecas locais)
- Tratamento de Erros e Exceções (`try` / `except`)
- Leitura e escrita em arquivos de texto (`.txt`)
